# Weight Calculator (rebuilt)

A native desktop app that recreates the features of the original VB6
"Weight Calculator" (Lalta Prasad, v3.0) with a new, modern interface.

## Sharing with users (no Python needed)

Give users **`dist/WeightCalculator.exe`**. It is a single self-contained
file. They double-click it and the app opens; nothing else needs to be
installed.

To rebuild the exe after making changes, double-click `build_exe.bat`
(or run it from a terminal). It regenerates the icon and writes a fresh
`dist/WeightCalculator.exe`.

## Running from source

Requires Python 3.8+ and Pillow (`pip install -r requirements.txt`).
Double-click `run.bat`, or from a terminal:

```
python main.py
```

## What's included

- **Solid Shaft / Round Bar** — diameter x length
- **Hollow Shaft / Pipe** — external/internal diameter x length
- **Box Section** — rectangular hollow section
- **Plate** — length x width x thickness
- **Beam Section** — Standard IS beams (ISJB/ISLB/ISMB/ISWB/ISHB/Provisional) or a custom I-section
- **Channel Section** — Standard IS channels (ISJC/ISLC/ISMC/ISCG) or custom
- **Angle Section** — Standard IS equal & unequal angles, or custom
- **Tee Section** — Standard IS tee bars (ISNT/ISDT/ISLT/ISMT) or custom
- **Specific Gravity** reference table
- **Unit Converter** — length & weight, plus the original's reference facts

## How the calculations work (matches the original exactly)

Every shape uses the same underlying rule:

```
weight (kg) = cross-section area (mm²) x length (mm) x specific gravity (g/cm³) x 1e-6
```

This is the standard volume x density formula, and it's been checked
against the well-known steel-industry shortcut `kg/m = d² / 162` for round
bars, and against expected values for plates, pipes, and standard sections
(see `test_calculations.py`).

- **Round bar / pipe / box / plate**: exact geometry, no approximation.
- **Beams & channels**: `Area = 2 x (flange width x flange thickness) + (web height x web thickness)`
  (ignores root fillet radii — the same simplification this class of
  calculator traditionally uses).
- **Angles**: `Area = thickness x (leg A + leg B − thickness)`
- **Tees**: `Area = (flange width x flange thickness) + (web height x web thickness)`

## About the Standard Section tables

The original program's exact internal dimension tables for ~140+ standard
beam/channel/angle/tee designations are compiled into its executable and
can't be cleanly extracted without running the program. The dimensions
included here (`core/sections.py`) are instead sourced from published
Indian Standard (IS 808 / IS 1852 / IS 1173) references — the same
standards the original almost certainly draws from — covering the most
commonly used sizes in each series.

**If you spot a standard size that doesn't match your original app**, or
need a size that isn't listed, switch to **Custom / General Section** mode
on that page — it uses the identical formula and lets you type any
dimensions directly (from a mill certificate or the IS handbook), giving
an exact result regardless of the preset table.

## Specific Gravity values (from the original app)

| Material | Specific Gravity |
|---|---|
| Aluminium | 2.70 |
| Brass | 8.45 |
| Bronze | 8.73 |
| Cast Iron | 7.20 |
| Copper | 8.96 |
| Steel — C15 | 7.85 |
| Steel — C35 | 7.84 |
| Steel — C60 | 7.83 |
| Lead | 11.34 |

Note: the standard structural section tables (beams/channels/angles/tees)
are steel-only, matching the original — aluminium/brass/bronze don't come
in these standardized rolled shapes, so they're only used with the basic
shape calculators (round bar, pipe, box, plate).

## Interface

- Every shape has a 3-D illustration on the home screen. Each calculator
  page shows a dimensioned diagram that redraws as values are typed, so
  the drawing matches the section being calculated.
- Results update live: total weight, cross-section area, weight per metre
  (per m² for plates) and weight in pounds.
- **About** (bottom of the sidebar) shows version, author and copyright.
  These details live in `gui/app_info.py`, and the exe's file properties
  come from `version_info.txt`.

## Project structure

```
main.py                  entry point
gui/
  app.py                 main window + sidebar navigation
  app_info.py            name, version, author, company, copyright
  theme.py               colours, fonts, DPI scaling, ttk styling
  widgets.py             reusable UI components
  diagrams.py            shape illustrations and dimensioned diagrams (Pillow)
  pages.py               one page per calculator / reference tool
core/
  materials.py           specific gravity table
  sections.py            IS standard section dimension tables
  calculations.py        weight/area formulas
assets/                  icon.png / icon.ico (generated by tools/make_icon.py)
tools/make_icon.py       draws the app logo and Windows icon
build_exe.bat            builds dist/WeightCalculator.exe with PyInstaller
version_info.txt         exe file properties (company, version, copyright)
test_calculations.py     formula sanity checks (run: python test_calculations.py)
```
